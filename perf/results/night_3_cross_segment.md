# 第3项跨分段修复

1. **改了什么**：保留 `_layout_stacked_panels` 返回的 `track_order`，只把连击代表面板映射到当前状态 ID；跨分段的 existing 事件不再 coalesce，直接按已布局路径恢复；新增跨分段连击与新礼物不重叠测试。
2. **为什么这样改**：避免下一段重建时把退场事件混入顺序，也避免把已有药丸的完整路径压成单点后被判定为已退场。
3. **遇到的问题和解决办法**：初版跨段测试暴露 existing 与新面板入口阶段同一 Y 的情况；确认新面板在入口动画期间位于外侧，进入后与已有药丸分别占据不同 Y 槽位，修正测试以检查可见阶段的最终槽位。
4. **意见和想法**：连击状态组只对当前 newcomers 合并；跨段接续不跨窗口重新聚合，保持已有布局状态，符合5秒窗口的分段边界语义。
5. **整体看法**：136 项 CPU/结构测试通过；交错切换、后续推挤、跨段接续均通过。本轮仍停在第3项。
6. **给 Claude 的建议**：请审查 track_order 映射和跨段 existing 处理；第3项完成后等待用户决定是否开始第2项少数方向重渲染。

机器：i7-14700KF / RTX 4070 Ti SUPER；实际修复用时约 25 分钟。
