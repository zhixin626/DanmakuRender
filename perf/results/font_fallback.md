# 第 9 项：字体回退链

状态：代码、单测和配置完成；同一素材的前后性能短基准因当前 DMR 正在渲染/合并而等待 gate，未擅自占用 GPU。字簇切分修复已追加。

1. **改了什么**：`SpriteFactory` 增加基于 fontTools cmap 的回退链和缓存；文字段按字簇和实际覆盖字体切分，测量与绘制共用同一组 runs；`PillowText`、GPU atlas 和面板绘制透传 `fallback_fonts`；默认配置加入 Windows 回退顺序；新增回退命中、缺字告警和越南语/泰文/组合重音字簇测试。
2. **为什么这样改**：主字体缺少韩文、泰文、阿拉伯文、符号或数学字母时，Pillow 不再直接画方框；回退字体按 cmap 选择，避免逐字解析字体文件。
3. **遇到的问题和解决办法**：字体名解析对路径型回退字体会再次走 matplotlib，已修为文件路径直接加载；缺少所有字体的码点回到主字体并按码点只警告一次。
4. **意见和想法**：回退字体和主字体使用同一字号，保持基线/行高稳定；面板和滚动精灵共用同一 SpriteFactory，测量/绘制不会漂移。
5. **整体看法**：实现覆盖第8项多语种演示的缺字风险，当前相关回归 37 passed、全量 CPU 测试 154 passed；性能是否超过 5% 需在 gate 放行后补测。
6. **给 Claude 的建议**：请审查 cmap 分段、路径型字体配置和缺字警告策略；当前门禁报告 DMR 有 6–13 个渲染任务，短基准待空闲后马上运行，结果会补入本文件后再进入 10a。

机器：Intel Core i7-14700KF / NVIDIA GeForce RTX 4070 Ti SUPER。基准脚本：`perf/font_fallback_bench.py`。
