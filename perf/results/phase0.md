# 阶段 0：Emoji 渲染基线

## 素材与选择理由

所有原始录像和 JSONL 只读；裁剪副本、RenderPlan、ASS、日志和统计均位于 perf/tmp/。
阶段 0 使用以下已完成录像：

- **分辨率切换-22点50分**：前端裁剪 300.000s，画布 1920×1080，50fps；布局事件 773（丢弃 1696），RenderPlan raster 事件 124，JSONL 记录 2469。
  - 原始视频：D:\DanmakuRender\Tasks文件\有问题的视频测试\分辨率切换\1\7月30日22点50分.flv
  - 原始弹幕：D:\DanmakuRender\Tasks文件\有问题的视频测试\分辨率切换\1\7月30日22点50分.jsonl

选择理由：该段前 300 秒含 27 条 Emoji/表情相关记录和 754 条礼物记录，RenderPlan raster 事件数高，且为已结束录像；排除了名称含 [正在录制] 或 .part 的文件。

## 测量环境

- CPU：Intel(R) Core(TM) i7-14700KF
- GPU：NVIDIA GeForce RTX 4070 Ti SUPER
- ffmpeg：ffmpeg version 2025-12-10-git-4f947880bd-full_build-www.gyan.dev Copyright (c) 2000-2025 the FFmpeg developers
- DMR 状态：开始前通过进程列表未发现 DMR 的 ffmpeg 或 emoji_render_mt.py 渲染进程；录制进程数量无法从当前受限进程接口可靠读取。
- 编码参数：hevc_nvenc -b:v 4M、aac -b:a 128K，解码 -hwaccel auto。
- 每组 3 次；各组按 A→B→C→D→E→F 交替执行；每组前空闲背景采样 30 秒，运行中 CPU 每 0.5 秒采样一次。
