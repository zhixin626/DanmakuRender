# 第1项：失败任务不跨重启保留

1. **改了什么**：撤销 `Render` 初始化时的 `load_failed_tasks()`，撤销所有 `save_failed_tasks()` 调用；保留两个原函数定义和当前进程内存中的 `failed_tasks`/WebUI 重试路径。新增启动不读取旧失败文件的测试，并调整停止/失败重试测试。
2. **为什么这样改**：按用户决定恢复原分支行为，失败列表只在本次运行有效，重启后清空；停止任务仍能在当前 WebUI 中重试。
3. **遇到的问题和解决办法**：原测试覆盖了跨重启恢复和文件写入，已改为验证旧文件不影响新实例、停止后文件不生成；未改用户生产目录和配置。
4. **意见和想法**：`load_failed_tasks`/`save_failed_tasks` 函数按要求保留，当前无调用方；后续若要持久化应另行决策。
5. **整体看法**：133 项 CPU/结构测试通过，失败任务行为回到可控的单次运行内存模型，不影响停止后人工重试。
6. **给 Claude 的建议**：请审查 Render 失败路径是否仍只依赖内存 failed_tasks，以及 WebUI 重试/忽略行为是否完整保留。
